## 2 · H-5F — Egress

### 2.1 · Dos controles diferenciados

| Control | Mecanismo | Estado (en el contenedor `factory-api`) |
|---|---|---|
| `PROCESS_LEVEL_CONTROL` | monkeypatch `socket.connect/​connect_ex` (`local_only.network_locked`) — **defensa adicional, NO prueba de aislamiento** | `ENFORCED` |
| `NETWORK_LEVEL_CONTROL` | red `factory_isolated` + `NET_ADMIN` + `factory_egress_guard.sh`: `iptables -P OUTPUT DROP` + allowlist (lo / established / 127·0·0/8 / `172.29.71.1:11434` / `172.29.71.0/24`) + REJECT `icmp-net-unreachable` para todo lo demás | `ENFORCED` |
| `EGRESS_GUARANTEE` | `FORBIDDEN` **solo si ambos** `ENFORCED`; en cualquier otro caso `BEST_EFFORT_PROCESS_ONLY` | `FORBIDDEN` |

La atestación **nunca** declara `NETWORK_LEVEL_CONTROL=ENFORCED` por el monkeypatch:
`egress_control_state()` lo deriva de `probe_external_reachability()` (un único SYN a
`1.1.1.1:53` / `8.8.8.8:53`, 0 bytes de payload, fuera de `network_locked()`), que devuelve
`BLOCKED` solo cuando el kernel responde `ENETUNREACH`.
