═══ D — AUTONOMOUS_BUILD_ORCHESTRATOR.PY ═══════════════════════════════════

Crea o completa factory/layer8/autonomous_build_orchestrator.py:

  run_build_mission(project_id: str) -> dict
    1. Lee misión de Capa 9 (mission_control.get_mission)
    2. Valida: status=approved, run_claude_code en allowed_actions
       (usa autonomy_policy_engine.validate_action)
    3. Verifica headless_enabled=True → si no: return {status:"error", reason:"headless_disabled"}
    4. apply_policy: genera settings.json acotado para el workspace
    5. validate_workspace + validate_task_safety (de claude_runtime)
    6. Crea job en factory/jobs/pending/ (job_type="headless_run")
    7. Registra layer8_autobuild_started en audit (añadir a VALID_EVENTS)
    8. Llama a host_worker.poll_and_execute(once=True)
    9. Lee el resultado: si returncode != 0 → layer8_autobuild_failed + return error
    10. Registra layer8_autobuild_completed
    11. Return {status:"completed", job_id, log_file, returncode}

  check_and_stop(event: str, project_id: str, mission_approval: dict) -> bool
    Llama a autonomy_policy_engine.check_stop_condition.
    Si True: layer8_stop_condition_triggered + host_worker.reset_headless_after_job.

═══ E — TEST_EXECUTION_MANAGER.PY ══════════════════════════════════════════

Crea factory/layer8/test_execution_manager.py:

  run_tests(project_id: str,
            cmd: str = "python3 -m pytest tests/ -q --tb=short",
            timeout: int = 120) -> dict
    - subprocess.run(cmd.split(), cwd=workspace, capture_output=True, timeout=timeout)
    - parsea stdout para extraer passed/failed/skipped/errors
    - guarda workspace/test_report.json
    - registra tests_executed en audit (añadir a VALID_EVENTS si falta)
    - return {project_id, all_passed, passed, failed, skipped, errors,
              output_preview(primeros 600 chars), cmd, duration_seconds, timestamp}

═══ E — GATE_EXECUTION_MANAGER.PY ══════════════════════════════════════════

Crea factory/layer8/gate_execution_manager.py:

  run_gates_for_mission(project_id: str, api_port: int,
                        api_key: str, fast: bool = True) -> dict
    - llama quality_gate_runner.run_deployment_gates (ya existe en core/)
    - si all_pass=False → layer8_stop_condition_triggered con event=gate_fail
    - return {all_pass, summary:{PASS,FAIL,SKIPPED}, gates, report_hash}

  run_static_gates(project_id: str) -> dict
    Para misiones sin deployment Docker: corre solo G01(compose config),
    G11(key no en UI), G12(git status). Útil para módulos que no levantan Docker.
    - return {all_pass, gates, summary}
