CONTEXTO Y MEJORAS RESPECTO AL ARQ W3
============================================================
El ARQ pide un endpoint /full-detail con 9 secciones en un solo JSON, y
un endpoint /artifact paralelo a los existentes. Las mejoras de W3:

  (1) SPLIT del endpoint: /summary (rápido, ~5 KB, cacheable con ETag) +
      secciones lazy /design /agents /headless /tests /rc /deployment
      /audit. El frontend carga summary primero, expande secciones bajo
      demanda. Evita martilleo de disco en cada refresh.

  (2) REUTILIZAR política de rutas U7 (factory/core/path_policy.py).
      No crear endpoint /artifact paralelo: extender los allowlist
      existentes a designs/ y deployments/. Una política, varios
      consumidores, menos superficie.

  (3) PARSEAR el log JSONL del headless en backend. Hoy es 1 línea de
      ~3 KB con JSON anidado (resultado, modelUsage, costos, turns).
      Exponer campos individuales para que la UI no parsee formatos
      internos del CLI.

  (4) VISTA DE PROFILES vs AGENTS NUEVOS — distinción clave de Capa 8.
      En oos_hplc_investigator hubo 2 profiles heredados (qa_oos_profile,
      integrity_lims_profile) + 1 agent nuevo (hplc_data_review_agent).
      Esa decisión es informativa y debe destacarse.

  (5) CACHING con ETag en /summary para que polling de UI no re-lea
      disco si nada cambió desde el último refresh.

REGLAS DURAS
  - No ejecutar headless. No deploy. No Docker nuevo.
  - No tocar app/, .env, docker-compose base, data/, backups/, aria-*, hotelbot-*.
  - No exponer secretos: .env, .claude/, .ssh/, credentials.json, *.key, *.pem.
  - No exponer build artifacts: __pycache__, .pytest_cache, *.pyc, *.bin.

# Devuelve solo metadatos consolidados, sin contenido de archivos.

#     "approved_by": "cesar"
#   },
#   "design": {
#     "files_count": 6,
#     "agents_summary": {
#       "profiles_inherited": 2,
#       "new_agents": 1,
#       "agent_ids": ["qa_oos_profile", "integrity_lims_profile", "hplc_data_review_agent"]
#     },
#     "pending_documents_count": 3
#   },
#   "workspace": {
#     "files_visible": 13,
#     "py_files": 8,
#     "has_test_report": true,
#     "has_headless_log": true
#   },
