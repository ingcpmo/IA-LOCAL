El CLI de Claude Code (claude -p) en el host se autentica con:
  - Sesión de claude.ai (si hiciste 'claude auth login' en el host)
  - Variable de entorno ANTHROPIC_API_KEY (si tienes API key de Anthropic)

Para usar tu cuenta ing.cpmo@gmail.com:
  1) En tu máquina local: abrir https://console.anthropic.com
  2) Generar una API key en "API Keys"
  3) En el servidor: export ANTHROPIC_API_KEY='sk-ant-...'
     (o agregar a ~/.bashrc sin comitear al repo)
  4) Verificar: echo "OK" | claude -p --output-format json

La API key de la FACTORY (b20a5e5bc90fceaa76703a53b5e09be4) es diferente:
  - Es la clave de factory-api (autoriza acceso a los endpoints de Mission Control)
  - NO es la clave de Anthropic para el CLI de Claude Code
  - Son dos sistemas de autenticación completamente distintos

El host_worker.py ejecuta claude en el HOST como usuario ing_cpmo.
Si la API key de Anthropic no está disponible en el entorno del host,
el headless fallará con error de autenticación aunque el CLI esté instalado.
