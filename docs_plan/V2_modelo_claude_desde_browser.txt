PREGUNTA: ¿Es viable autenticar Claude Code desde el browser y elegir el modelo?

RESPUESTA CORTA: Parcialmente. La autenticación del CLI NO puede delegarse al
browser (la clave de Anthropic nunca debe tocar el frontend). Pero la elección
del MODELO y la visualización del estado de autenticación SÍ son viables y
se pueden agregar con 3 componentes sobre la arquitectura actual.

ARQUITECTURA ACTUAL (lo que ya existe):
  Browser → POST /layer8/missions/{id}/headless → factory-api (contenedor)
                                                        ↓
                                               host_worker.py (host)
                                                        ↓
                                        claude -p --permission-mode auto [modelo fijo]

ARQUITECTURA OBJETIVO (lo que V2 agrega):
  Browser → GET /layer8/claude/status  → muestra: autenticado, modelo activo
  Browser → POST /layer8/claude/config → cambia modelo (no la clave)
                                                        ↓
                                               host_worker.py usa modelo elegido
  Browser → POST /layer8/missions/{id}/headless/{modelo} → encola con modelo

LO QUE EL BROWSER NUNCA PODRÁ HACER (regla de seguridad inamovible):
  - Ver o modificar ANTHROPIC_API_KEY
  - Ver o modificar ~/.claude/ credentials
  - Autenticar por primera vez (eso siempre es una acción en el host)
  - Ver el output completo del CLI en tiempo real (solo el log post-ejecución)

MODELOS DISPONIBLES (a la fecha):
  - claude-haiku-4-5-20251001   → más rápido, más barato (~$0.08/job demo)
  - claude-sonnet-4-6           → balance calidad/velocidad (actual default)
  - claude-opus-4-6             → máxima calidad, más lento (~$1.5/job demo)
  - claude-opus-4-7             → frontier (si está disponible en tu plan)

IMPLICACIONES PART-11:
  El cambio de modelo es una DECISIÓN TÉCNICA con consecuencia en la calidad
  del código generado. Debe quedar auditado: quién cambió el modelo, cuándo,
  y qué job lo usó. V2 incluye esto en la cadena de auditoría.

# === V2: endpoint claude/config ===
# Agregar a factory/api/routes/layer8.py

from pydantic import BaseModel, validator

ALLOWED_MODELS = {
    "claude-haiku-4-5-20251001",
    "claude-sonnet-4-6",
    "claude-opus-4-6",
    "claude-opus-4-7",
}

class ClaudeConfigUpdate(BaseModel):
    model: str
    changed_by: str  # nombre real, mismo estándar Part-11 que approved_by

    @validator("model")
    def validate_model(cls, v):
        if v not in ALLOWED_MODELS:
            raise ValueError(f"Modelo no permitido: {v}. Permitidos: {ALLOWED_MODELS}")
        return v

    @validator("changed_by")
    def validate_changed_by(cls, v):
        reserved = {"human", "agent", "system", "admin", "user", "factory"}
        if not v or v.strip().lower() in reserved:
            raise ValueError(f"changed_by debe ser nombre real, no genérico: '{v}'")
        return v.strip()

@router.post("/claude/config")
def update_claude_config(body: ClaudeConfigUpdate,
                          api_key: str = Depends(verify_api_key)):
    """
    Actualiza el modelo de Claude Code para próximas ejecuciones headless.
    Requiere nombre real del responsable (Part-11).
    Auditado en la cadena.
    """
    import yaml, pathlib
    from factory.core.audit_writer import write_event

    rc_path = pathlib.Path("factory/runtime/runtime_config.yaml")
    config = yaml.safe_load(rc_path.read_text()) if rc_path.exists() else {}
    
    prev_model = config.get("claude_model", "claude-sonnet-4-6")
    config["claude_model"] = body.model
    config["model_changed_by"] = body.changed_by
    config["model_changed_at"] = __import__("datetime").datetime.utcnow().isoformat() + "Z"
    
    rc_path.write_text(yaml.safe_dump(config, sort_keys=False))
    
    # Auditar el cambio — es una decisión técnica con consecuencia
    write_event("claude_model_changed", "factory_config", extra={
        "prev_model": prev_model,
        "new_model": body.model,
        "changed_by": body.changed_by,
        "decision_origin": "human_confirmed"
    })
    
    return {
        "status": "updated",
        "prev_model": prev_model,
        "active_model": body.model,
        "changed_by": body.changed_by,
        "audit": "event registered in chain"
    }
