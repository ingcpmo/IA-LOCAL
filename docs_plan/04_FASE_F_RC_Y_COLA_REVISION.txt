═══ F1 — RELEASE_CANDIDATE_BUILDER.PY ══════════════════════════════════════

Crea o completa factory/layer8/release_candidate_builder.py:

  build_rc(project_id: str, version: str) -> dict
    1. Llama artifact_collector.collect(project_id, rc_id)
       donde rc_id = f"{project_id}-rc-{version}-{ts:%Y%m%dT%H%M%S}"
    2. Si collect falla (artefactos incompletos) → return {ok:False, ...}
    3. Escribe factory/release_candidates/<project_id>/<rc_id>/rc_manifest.json:
         {rc_id, project_id, version,
          status: "pending_human_confirmation",   ← NUNCA "approved"
          decision_origin: "agent_proposed",
          approved_by: null,
          artifacts_path, proposed_at, sha256sums}
    4. Genera SHA256SUMS de los artefactos
    5. Registra release_candidate_created en audit
    6. Llama a human_review_queue.enqueue(rc_id, project_id, summary)
    7. Return {ok:True, rc_id, status, artifacts_path}

  list_pending_rcs() -> list
    Lee factory/release_candidates/**/ buscando rc_manifest.json
    con status="pending_human_confirmation"

  get_rc(rc_id: str) -> dict
    Busca rc_manifest.json por rc_id en todos los subdirectorios.

  confirm_rc(rc_id: str, approved_by: str,
             decision: str, notes: str = "") -> dict
    decision: "approved" | "rejected" | "returned_to_adjustments"
    RESERVED = {"human","agent","layer8","system","capa8","capa9"}
    Si approved_by.lower() en RESERVED → raise ValueError
    Escribe: status=decision, approved_by, decided_at,
             decision_origin="human_confirmed"
    Registra release_candidate_approved/_rejected en audit
    Return {ok:True, rc_id, decision, approved_by}
