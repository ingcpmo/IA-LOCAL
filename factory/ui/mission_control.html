◆
MEMORIA LIGERA GOBERNADA (W6.4). Solo casos reales de fuentes oficiales: pointer + metadata + resumen + hash — nunca el documento completo. Cada caso muestra primero una interpretación determinista (relevancia desde la clasificación FDA, agente recomendado por señales) que NO es juicio GMP, y después la evidencia técnica. El detalle se recupera bajo demanda (selective fetch auditado). Esta información NO alimenta decisiones GMP ni aprobaciones CSV.

Flujo gobernado: consulta a fuente oficial → memoria ligera → búsqueda de casos similares → selective fetch del caso necesario → análisis por agente (W7: real, gobernado y auditado) → cita trazable → decisión humana con motivo → auditoría. "Analizar con agente" ejecuta el pipeline real (qwen local, verificador v2.1, ~7–9 min); "Comparar con misión" es cruce informativo read-only. El análisis es INFORMATIVO: no es evaluación de impacto GMP ni toca el dossier.
